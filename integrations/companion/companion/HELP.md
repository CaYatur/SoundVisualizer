## CaYaDev SoundVisualizer

1. In SoundVisualizer open **Control → OSC** and turn the OSC input on. Note the port (default 9000) and prefix (default `/cayadev`).
2. If Companion runs on another computer, make sure SoundVisualizer's OSC input accepts LAN traffic and your firewall allows the UDP port.
3. Enter the IP, port and prefix here.
4. Optional feedback: turn on **OSC output** in SoundVisualizer, point it at the Companion machine, and enter that port as "Listen for OSC output". Blackout, Auto VJ, now playing, BPM and opacity then update live.

Actions: blackout, Auto VJ, recall scene, visualizer/background mode, master opacity, crossfader, palette, layer opacity / on-off, clip deck launch / stop, timeline play / pause / stop, MilkDrop preset and any slider path.
